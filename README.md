# 🐍 EnsinoPy — Minha Jornada de Aprendizado em Python

## 📌 Sobre o repositório

Este repositório foi criado com o objetivo de registrar minha evolução nos estudos da linguagem **Python**, reunindo conteúdos aprendidos durante as aulas e exercícios realizados para desenvolver minhas habilidades em programação.

Aqui compartilho minha jornada de aprendizado, buscando aprimorar minha lógica de programação, minha capacidade de resolver problemas e meus conhecimentos em desenvolvimento de software.

## 📂 Organização do repositório

### 📚 Pasta `Aulas`

A pasta **Aulas** é destinada aos códigos e exemplos desenvolvidos durante meus estudos de Python.

Nela, registro os conceitos apresentados nas aulas, acompanhando explicações e realizando testes para compreender melhor o funcionamento da linguagem.

**Objetivos desta pasta:**
- Registrar os conteúdos estudados.
- Praticar os conceitos apresentados nas aulas.
- Consultar exemplos para revisar conhecimentos.
- Acompanhar minha evolução no aprendizado.

### 💻 Pasta `Pratica`

A pasta **Pratica** reúne exercícios que desenvolvo para aplicar os conhecimentos adquiridos durante as aulas.

O objetivo é fortalecer minha lógica de programação, desenvolver autonomia na escrita de códigos e aprender a solucionar problemas por meio da prática.

**Objetivos desta pasta:**
- Resolver exercícios de programação.
- Aplicar os conceitos aprendidos.
- Desenvolver o raciocínio lógico.
- Identificar erros e aprimorar soluções.
- Ganhar experiência prática com Python.

## 🎯 Objetivo dos estudos

Busco desenvolver minhas habilidades técnicas e me preparar para futuras oportunidades profissionais na área de tecnologia.
